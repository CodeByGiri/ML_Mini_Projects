# ML Mini Projects Portfolio

This repository contains a collection of machine learning and deep learning mini-projects completed as part of an internship and hands-on learning process.  
Each project is organized in its own folder and includes a dedicated README file explaining the dataset, approach, and key concepts used.

---

## 📁 Projects Included

### 1. Iris Flower Classification
- **Type:** Classification (Supervised ML)
- **Concepts:** EDA, feature selection, Logistic Regression
- **Dataset:** sklearn Iris dataset
- **Folder:** `Iris-Classification/`

---

### 2. House Price Prediction
- **Type:** Regression
- **Concepts:** Data preprocessing, feature engineering, Linear Regression
- **Dataset:** Custom housing dataset (CSV included)
- **Folder:** `House-Price-Prediction/`

---

### 3. Titanic Survival Prediction
- **Type:** Binary Classification
- **Concepts:** EDA, handling missing values, One-Hot Encoding, Logistic Regression
- **Dataset:** Seaborn Titanic dataset
- **Folder:** `Titanic-Survival-Prediction/`

---

### 4. Handwritten Digit Recognition
- **Type:** Image Classification
- **Concepts:** Image preprocessing, Random Forest, pixel-based features
- **Dataset:** sklearn Digits dataset
- **Folder:** `Handwritten-Digit-Recognition/`

---

### 5. Image Classification Using ANN (MNIST)
- **Type:** Deep Learning
- **Concepts:** Artificial Neural Networks, normalization, Dense layers
- **Dataset:** MNIST handwritten digits
- **Folder:** `Image_Classification_Using_ANN/`

---

### 6. Movie Recommendation System (Content-Based)
- **Type:** Recommendation System (NLP)
- **Concepts:** TF-IDF, Cosine Similarity, NLP
- **Dataset:** TMDB Movies Dataset (CSV included)
- **Folder:** `Movie-Recommendation-System/`

---

### 7. Credit Card Fraud Detection
- **Type:** Imbalanced Classification
- **Concepts:** Class imbalance, class weighting, Precision/Recall, ROC-AUC
- **Dataset:** Kaggle Credit Card Fraud Detection dataset  
  (Dataset not included due to size constraints)
- **Folder:** `CreditCardFraudDetection/`

---
